# 星辰笔记 · 产品说明

星辰笔记是一款面向个人和团队的本地优先知识管理工具。它支持 Markdown 编辑、
双向链接和全文检索，所有数据默认保存在用户自己的设备上。

## 定价

星辰笔记提供免费版和专业版。免费版支持无限本地笔记和基础同步。专业版每月
三十元，支持跨设备实时同步、版本历史和端到端加密。用户随时可以取消订阅，
已付款未使用的部分按比例退款。

## 数据隐私

所有笔记默认只存储在本地，不会上传到任何服务器。只有用户主动开启云同步时，
数据才会以加密形式传输。我们不会将笔记内容用于任何广告或模型训练。

## 支持的平台

星辰笔记目前支持 Windows、macOS 和 Linux 桌面端，以及 iOS 和 Android 移动端。
移动端与桌面端之间可以通过局域网直连同步，无需经过互联网。

## 常见问题

如何导入旧笔记？用户可以从 Notion、Evernote 和 Markdown 文件夹批量导入，
导入过程中会保留原有的目录结构和标签。加密笔记需要先输入主密码才能导出。
